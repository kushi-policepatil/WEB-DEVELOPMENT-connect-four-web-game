# Connect Four — by Kushi

A modern, responsive Connect Four game built with **HTML + CSS + JavaScript**.  
Includes **PvP** and **Player vs CPU** (Easy/Medium/Hard with minimax), **Undo**, and **score persistence** via LocalStorage.

## How to run
1. Download and unzip.
2. Open `index.html` in any modern browser.

## Features
- Clean UI with subtle animations.
- PvP and vs-CPU with three difficulty levels.
- Undo (in CPU mode, undo removes your last move and the CPU's move).
- Scores saved between sessions with `localStorage`.
- Accessible (ARIA labels, live regions).

## Deploy
- Drag-drop the folder into **Netlify**, **Vercel**, or serve with GitHub Pages.
